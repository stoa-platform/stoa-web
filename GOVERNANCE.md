# Gouvernance de stoa-web

Ce document concerne le site vitrine, pas l’ensemble des composants du produit. STOA est porté par CAB Ingénierie — France. Le dépôt historique désigne Christophe ABOULICAM comme mainteneur et autorité finale pour les décisions du projet.

Les propositions peuvent être discutées dans les issues et revues de ce dépôt. Les changements de licence, les informations légales et le contenu des offres nécessitent une décision de l’éditeur. Une prestation commerciale ne confère pas d’autorité sur la gouvernance du code publié.

Les instructions de contribution au produit et ses décisions d’architecture se trouvent dans les dépôts concernés ; ce dépôt ne publie pas de répertoire ADR ni de feuille de route externe vérifiée. Il n’affirme pas de gouvernance par une fondation, d’affiliation institutionnelle ni de contrôle CI dont l’exécution n’est pas démontrée ici.

Pour une question ou une escalade : contact@gostoa.dev. Les modalités de remplacement du mainteneur et de continuité doivent encore être précisées par l’éditeur.
