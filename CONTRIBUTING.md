# Contribuer à stoa-web

Ce dépôt contient le site Astro de STOA. Pour le produit, consultez les instructions du [dépôt STOA](https://github.com/stoa-platform/stoa) ou du [démarrage rapide](https://github.com/stoa-platform/stoa-quickstart).

Pour signaler une erreur de texte, de traduction ou d’accessibilité, indiquez la page, la langue, le comportement observé et le résultat attendu dans les issues du dépôt. Vous pouvez aussi écrire à contact@gostoa.dev. N’incluez pas de données personnelles ni de secrets dans un signalement public.

## Préparer une modification

Utilisez une copie de travail, npm et le lockfile du dépôt. Installez avec `npm ci`, puis lancez `npm run dev` et `npm run build`. Aucun outil Python, conteneur ou commande de déploiement n’est requis pour modifier le site.

Maintenez les clés des dictionnaires FR/EN alignées, les liens internes et les alternatives de langue symétriques. Respectez le système de tokens commun et le fonctionnement sans JavaScript. Vérifiez clavier, mobile et thèmes clair/sombre. Pour une modification de contenu, retirez les chiffres non sourcés, les promesses commerciales non confirmées et les affirmations de licence non délimitées.

## Origine des contributions

Le guide du dépôt demande une attestation DCO par une ligne `Signed-off-by` dans les contributions soumises. Le [Developer Certificate of Origin](https://developercertificate.org/) explique cette attestation d’origine. Aucun CLA distinct n’est fourni dans ce dépôt ; ne supposez pas qu’un contrôle automatisé existe. Les mainteneurs vérifient l’origine et le périmètre des changements lors de la revue.

Consultez le [code de conduite](CODE_OF_CONDUCT.md) et la [gouvernance du site](GOVERNANCE.md). Aucun achat de prestation n’est nécessaire pour participer.
